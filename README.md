# Niharika Joshi - Cybersecurity Analyst Portfolio

A high-performance, dark-themed, and responsive personal portfolio engineered for an aspiring Cybersecurity Analyst specializing in Defensive Security, Blue Team operations, Linux administration, and network analysis.

## ✨ Highlights & Features

- **Cybersecurity Dark Aesthetic**: Deep navy and dark slate palette (`#060913`, `#0F172A`) accented with cyber cyan (`#00F0FF`), electric violet (`#A78BFA`), and status emerald (`#10B981`).
- **3D Canvas Crystals Engine**: Interactive 3D wireframe crystals and cyber lattice particles rendered on an HTML5 canvas with mouse parallax reactivity.
- **Micro-interactions & Glows**: Ambient radial glow orbs, radar ping status indicator, smooth scroll reveal animations, and interactive card spotlights.
- **Interactive Project Filtering**: Instant filter tabs for Defensive & Systems, Networking & Logs, and Web & Portfolio with smooth CSS animations.
- **Embedded Lab Diagrams**: SVG architecture and terminal previews for each hands-on lab and project.
- **Toast & Copy Utilities**: One-click clipboard copy for email with animated toast progress bar.
- **Interactive Contact Form**: Real-time form validation with simulated dispatch telemetry state.
- **Full Responsiveness & Accessibility**: Mobile drawer navigation, skip link, high-contrast readable typography, and `prefers-reduced-motion` compliance.

## 🛠️ Tech Stack

- **HTML5**: Semantic document layout, SEO and Open Graph metadata
- **CSS3**: Custom design tokens, glassmorphism (`backdrop-filter`), CSS Grid & Flexbox, keyframe animations
- **Vanilla JavaScript (ES6+)**: Zero external dependencies, Canvas 3D projection, IntersectionObserver scroll reveals, stateful UI controls

## 🚀 Running Locally

Open `index.html` directly in any modern browser, or serve it using your preferred local development server:

```bash
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve
```
